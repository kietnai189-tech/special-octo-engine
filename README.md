# special-octo-engine
Web app sửa ảnh chạy trên trình duyệt, giao diện tối, dùng tốt trên điện thoại. Tải ảnh lên bằng nút hoặc kéo thả. Chỉnh sáng, tương phản, bão hòa, mờ, nét bằng thanh trượt. Có filter Đen trắng, Sepia, Cổ điển, Ấm, Lạnh. Cắt, xoay, lật ảnh, thêm chữ. Hoàn tác/làm lại, xem ảnh gốc để so sánh, tải về PNG hoặc JPG. Không lỗi console, code gọn.
